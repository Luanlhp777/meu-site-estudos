Sobre o projeto

O Coguis Informática é um projeto desenvolvido para estruturar a presença digital de uma operação real de tecnologia, reunindo serviços de manutenção de computadores, suporte técnico, soluções digitais e desenvolvimento web em uma plataforma institucional.


Além da apresentação dos serviços, o projeto também funciona como base para estratégias de presença digital, produção de conteúdo técnico e comunicação com clientes.


O desenvolvimento envolveu organização da arquitetura do site, criação de páginas institucionais, implementação de layout responsivo, estruturação de componentes reutilizáveis e publicação contínua utilizando Git e GitHub Pages.
